Carreteras de Zona 4 Trujillo (Sur-Este)

Mapa de carreteras, puntos kilométricos y poblaciones sobre fondos del IGN.

En el ordenador

  1. Abre Mapa_Zona4_IGN.html con doble clic (Chrome o Edge).
  2. Elige el fondo: Topográfico, Mapa base, Ortofoto o Sin fondo.
  3. Escribe en la única caja de búsqueda (CC-432, Trujillo, Navezuelas…). Si hay varias coincidencias, elige en la lista: Carretera (Trujillo → CC-330) o Población (Trujillo → pueblo).
  4. “Medir distancias”: clic en el inicio y en cada punto; muestra tramos y total.
  5. El cuadradito de color cambia el color y el desplegable de grosor (Fino, Medio, Normal, Grueso, Muy grueso) cambia la anchura de las carreteras; la seleccionada se resalta.
  6. Pulsa en cualquier punto del mapa: panel con WGS84 (lat/lon) y ETRS89 UTM (Este/Norte). El huso se calcula solo: 30N en la Zona 4 y 29N si entra una carretera más al oeste. Botón Copiar.

Instalar en GitHub Pages

  1. Crea un repositorio público (ej. zona4-mapa).
  2. Sube los 3 archivos de GitHub Pages\Zona4: index.html, README.md y .nojekyll.
  3. Settings → Pages → Source: Deploy from a branch, rama main, carpeta /(root) → Save.
  4. Espera 1-2 min y abre https://TU-USUARIO.github.io/zona4-mapa/ (con la barra final).

En el iPhone

  1. Abre Safari y pega la URL https://... (nunca http://).
  2. Pulsa Mi ubicación → Permitir.
  3. Compartir → Añadir a la pantalla de inicio para usarlo como app.

En Android

  1. Abre Chrome y pega la misma URL https://....
  2. Pulsa Mi ubicación → Permitir (también puedes ir a Ajustes → Apps → Chrome → Permisos → Ubicación).
  3. Menú de Chrome (⋮) → Añadir a pantalla de inicio o Instalar app.
  4. Si no sale el permiso: activa la ubicación del móvil y en Chrome elige Solo mientras usas la app o Preguntar cada vez.
Importante: el GPS del móvil (iPhone y Android) solo funciona con la URL HTTPS de GitHub Pages. Desde un archivo local no permite la ubicación. Para actualizar el mapa, sustituye index.html en el repositorio y haz Commit changes.
